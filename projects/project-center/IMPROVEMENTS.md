# Журнал улучшений

## 16 сентября 2026 — диагностика сбоев ИИ

Подготовлены безопасные коды ошибок: запуск Codex, завершение процесса без ответа, тайм-аут, превышение объёма и пустой ответ. Диалог показывает понятную причину и следующий шаг. Неизвестные ошибки получают общее сообщение; исходный текст исключений пользователю не передаётся.

Адаптер записывает в стандартный журнал ошибок только время, безопасный код и числовой код завершения процесса. Переписка, ключи и вывод провайдера не записываются. Для неизвестного завершения процесса точная сетевая или серверная причина по-прежнему может потребовать отдельной диагностики.

Проверено на отдельных тестовых базах: сценарии ошибок адаптера и отсутствие утечки текста; API диалогов с известной и неизвестной ошибкой; регрессии диспетчера и интерфейса диалогов. Все проверки прошли. Рабочая база не изменялась.

Резервная копия изменённых исходников: `work/backup-ai-errors-20260916-1415` относительно корня задачи.

**Применение:** требуется перезапуск работающего сервера. Он оставлен работающим на прежнем коде: отсутствие незавершённых пользовательских операций не подтверждено. Перед перезапуском проверить генерации, поручения и пользовательские формы; перезапуск завершит текущие сеансы входа.

Осталось: применить подготовленное изменение в безопасный момент и проверить отображение кода ошибки в браузере на отдельной базе. Автоматический повтор запросов не добавлялся, чтобы не дублировать обращения и расход лимита.
