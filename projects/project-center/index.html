Мой пароль

После смены пароля все ваши сеансы будут завершены.

Сотрудники

Администратор управляет сотрудниками. Редактор ведёт учёт. Наблюдатель просматривает данные.

Резервная копия

Экспортируйте данные регулярно для резервного копирования. Импорт JSON заменяет текущую базу.

Импорт продаж из CSV

Сначала добавьте товары с соответствующими артикулами. Импорт добавляет продажи; повторная загрузка создаст дубликаты. Это собственный формат приложения, не прямой импорт отчёта Ozon.
