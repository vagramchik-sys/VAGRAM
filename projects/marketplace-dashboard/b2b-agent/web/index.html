Что передать администратору 1С

Нужен внутренний HTTP-сервис для чтения товаров, клиентских цен, свободных остатков, единиц измерения, НДС и сроков. Формат интеграции описан в документации проекта. Ввод адреса обычной базы или веб-клиента 1С сам по себе интеграцию не создаёт.
