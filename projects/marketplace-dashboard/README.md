# Пульт: локальное приложение

Запуск из этой папки: `node server.cjs`. Нужны Windows и Node.js 20 или новее.

Адрес: http://127.0.0.1:4317/

Главная страница показывает реальные данные пяти магазинов: общий каталог, поиск, фильтры себестоимости и остатков, карточки товаров, CSV и динамику начислений Ozon. Настройки подключения — /connections.html. Старый демонстрационный экран сохранён по адресу /demo.html; зеркало работает отдельно.

Ключи зашифрованы Windows DPAPI для текущей учётной записи и сохраняются в .private/stores.json. Снимки данных находятся в .private/data-*.json; не включайте эту папку в публикацию сайта. Папка исключена из git. Сервер доступен только на этом компьютере.

Ozon: товары, остатки, ежедневные начисления за 30 календарных дней, включая текущий неполный день. Финансы используют /v1/finance/accrual/by-day с последовательным чтением всех страниц.

Wildberries: карточки, остатки складов WB и детализация ежедневных финансовых отчётов. Обновление зависит от задержек публикации отчётов площадкой. Себестоимость Ozon импортируется вместе с товарами; нулевые значения отмечены для проверки. Расчёт чистой прибыли пока не выполняется: нужно проверить расходы и количество продаж, сопоставить себестоимость с датами продаж. Отдельные рекламные отчёты ещё не импортируются.

После перезапуска сервера обновите страницу браузера. Завершённые данные сохраняются; незавершённый импорт можно запустить кнопкой «Обновить данные». Во время импорта не останавливайте сервер.

Проверки: `node --test test/dashboard.test.cjs`. Кнопка «Проверить обновления» перечитывает локальные снимки; кнопка в карточке магазина запускает импорт из площадки.
В рабочем обзоре по умолчанию скрыты архивные товары Ozon и товары со статусом «Не продаётся». Переключатель позволяет вернуть полный каталог; выбор хранится в браузере. Фильтр влияет на товарные показатели, таблицу и CSV. Исторические финансы сохраняют все операции. Статусы WB не импортированы, поэтому по этому признаку WB не скрывается.
# Управление товарами

Раздел `http://127.0.0.1:4317/manage.html` работает с реальными товарами подключённых магазинов. Ссылка есть в боковом меню и карточке товара основного дашборда.

- Цены обновляются отдельной кнопкой по выбранным магазинам, без повторного импорта финансов. Ozon: `/v5/product/info/prices`; WB: `GET /api/v2/list/goods/filter` с пагинацией до пустой страницы. [Документация WB](https://dev.wildberries.ru/en/openapi/work-with-products).
- Для Ozon доступны черновики базовой, минимальной цены и цены до скидки; для WB — базовой цены и скидки продавца. Разные цены по размерам WB пока блокируют редактирование. Нулевая цена из API показывается как ноль и сопровождается предупреждением при подготовке новой цены.
- Массовые операции: процент, прибавление/вычитание рублей, фиксированная цена, наценка от заполненной себестоимости. Округление к ближайшему рублю, 10 или 100 рублям, либо до копеек.
- Перед сохранением сервер пересчитывает изменения, сверяет версии товара, валюту, минимальную цену, актуальность снимка (24 часа) и предупреждения. Повтор запроса не создаёт вторую заявку; один товар не может одновременно попасть в два открытых черновика/заявки на проверке.
- Заявки: черновик → на проверке → возврат с причиной или отмена. Подтверждение руководителя и отправка на площадки **ещё не реализованы**: текущие ключи предназначены для чтения, отдельной аутентификации сотрудников нет. Статусы используются для подготовки в общем локальном рабочем месте, а не как защищённое разграничение прав. Уведомления не отправляются.
- Заметки и метки «Проверить» / «К закупке» сохраняются локально. Каталог и заявки выгружаются в CSV с защитой от формул в текстовых ячейках.

Заявки, заметки и журнал хранятся в `.private/management.json`; цены WB — в `.private/prices-<id>.json`, цены Ozon вместе с себестоимостью — в `.private/costs-<id>.json`. В этих файлах нет новых API-ключей. Черновики не меняют импортированные цены и не вызывают методы записи площадок. Основной обзор продолжает учитывать все исторические финансовые операции.

Проверка: `node --test test/dashboard.test.cjs test/management.test.cjs`. Интерфейс сохранения заявки, передачи на проверку, возврата и заметок проверен отдельно на тестовом магазине; рабочие заявки не создавались.
