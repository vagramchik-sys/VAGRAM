# Категории по каталогу СтальКрепеж

Источник навигации: https://stalkrepej.ru/ . В `stalkrepej-category-tree.json`
сохранены публичные названия, вложенность, ссылки и дата чтения меню.
Цены, описания товаров и данные магазинов в этот файл не входят.

`product-category-site-mapping.cjs` сопоставляет ранее проверенный тип товара
и явно известные характеристики с существующим разделом сайта. Если точный
подтип не подтверждён, используется подходящий родительский раздел. Товар без
надёжного соответствия остаётся в «Не сопоставлено с каталогом сайта».

После навигации сайта идут товар с известными характеристиками и упаковка,
если остаётся место в пяти уровнях. В глубоких ветках варианты упаковки
представлены отдельными карточками магазинов под товаром. Артикулы и SKU
сохраняются. Пропуски и противоречия характеристик не заполняются догадками.

Предварительный просмотр:

```powershell
node scripts/refine-product-categories.cjs --stalkrepej
```

Применение к локальному справочнику Пульта:

```powershell
node scripts/refine-product-categories.cjs --stalkrepej --apply
```

Команда читает локальный каталог SQL, делает приватную резервную копию
справочника и сохраняет его через compare-and-set. При конкурентном изменении
запись отклоняется. Заказы, финансовые строки и карточки маркетплейсов не
меняются. Повторная сборка с теми же исходными данными не создаёт новых веток.
Старая команда `--rebuild-product-pack` распознаёт версию `stalkrepej-*`
и сохраняет новую структуру. Сеть в пользовательские запросы не добавляется.
