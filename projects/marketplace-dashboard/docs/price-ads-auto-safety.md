# Автоматическое управление ценой и рекламой: условия запуска

Пульт рассчитывает рекомендации локально. Автоматические записи в Ozon сейчас выключены: `priceWrite=false`, `bidWrite=false`, `auto=false`. Экран товара показывает причины `HOLD`; само открытие страницы ничего не меняет у продавца.

## Ограничения владельца

- Целевая прибавка цены — 2%. Если **подтверждённый Ozon API** минимальный шаг больше, возможна цена после этого шага, но не более +5%. Индекс цены, фактический коридор цены покупателя и риск конверсии должны быть проверены именно для конечной цены. Иначе `HOLD`.
- Рекламная ставка — максимум +5% за шаг, не чаще одного раза в 12 часов на SKU. `recommendedBid` должен быть не выше `maxProfitableBid`. Конкурентная ставка сама по себе не даёт разрешения на повышение.
- Предыдущий шаг ставки должен быть оценён на полном сопоставимом окне не короче 12 часов, как минимум со 100 кликами и 10 заказами, без ухудшения прибыли. Подтверждённая исходная статистика не заменяет оценку предыдущего шага; без него первый автоматический шаг остаётся `HOLD`.
- Расходы на рекламу SKU за 30 завершённых дней — не более 15% подтверждённой выручки этого же SKU. Дополнительно нужен реально работающий ограничитель будущих расходов. Прибыль после рекламы должна оставаться выше заданного минимума.

## Что пока не даёт включить записи

У доступных данных Seller API нет подтверждённого минимального шага изменения цены для конкретного товара и достоверной цены, которую увидит покупатель после скидок. Действующий источник рекламных ставок хранит исходные единицы Performance API без доказанного пересчёта в рубли за клик. Финансовый и рекламный потоки имеют разную атрибуцию; полный сопоставимый расчёт за 30 дней по SKU и результат предыдущего шага отсутствуют. Ограничитель будущих расходов также не подключён.

Отдельный транспорт для цены умеет проверить текущую цену, выполнить **одну** запись и сверить результат чтением. Он не подключён к маршрутам или фоновому исполнителю. Повтор после неопределённого ответа запрещён. Транспорт для записи рекламных ставок не подключён. До появления перечисленных источников нельзя переключать `AUTO` или запускать исполнитель, даже если чистые тестовые данные дают `READY` в проверке политики.
