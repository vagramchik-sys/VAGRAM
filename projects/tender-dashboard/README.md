# Панель тендерного отдела

Откройте `dist/index.html` в браузере. Это статическая панель с демонстрационными данными, портфелем тендеров, сроками и черновиками документов.

Отправка писем, подача заявок на площадки и серверная аутентификация не подключены. Локальные пользовательские данные браузера в репозиторий не включены.
