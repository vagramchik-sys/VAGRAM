# Исходники АТЛАС

`source.json` — проверенный текстовый снимок исходников приложения, включая TypeScript, миграции, тесты и вымышленные примеры. Формат сохраняет исходные пути и содержимое; сборка и рабочая база сюда не входят.

Снимок используется потому, что текущий синхронизатор VAGRAM не переносит файлы `.ts`, `.tsx` и `.sql` напрямую. Работающее приложение остаётся в прежней папке. Не редактируйте снимок вручную: обновляйте исходный проект, проверяйте и создавайте новый снимок.

Для восстановления в новую пустую папку:

```powershell
node restore.cjs C:/Projects/atlas-restored
```

Затем установите зависимости по `package-lock.json`. Для размещения нужен новый приватный проект с D1; существующий идентификатор публикации и настройки подключений намеренно исключены. Тестовые данные не содержат сведений реальных компаний.

Функции: заказы покупателей и поставщикам, счета с печатью, товарные накладные, частичные поставки и оплаты, авансы и долги, расходы, складские остатки, средняя себестоимость, перемещения, оприходования и списания. Черновики редактируются, проведение и отмена сохраняют историю. Отчёты объединяют новые операции и прежние документы. Рабочая и тестовая базы изолированы. Справочники включают товары/услуги, организации с банковскими реквизитами, склады и статьи расходов. Примеры JSON предназначены для просмотра и тестирования; импорт не реализован. НДС, резервы, возвраты, производство, зарплата и обмен с 1С пока не включены. Раздел «Контроль» находит просрочки и дефицит запасов к срокам, показывает объяснения и документы-основания. Прогноз денег учитывает введённый остаток, частичные оплаты и выбранный сценарий поступлений; заказы не дублируют долг. Подробные правила и ограничения — в TRADE.md.

Проверки исходного проекта: `node --experimental-strip-types --test tests/demo.test.mjs tests/trade.test.mjs tests/insights.test.mjs`, `node tests/demo-api.mjs` и `node tests/trade-api.mjs` при запущенном локальном приложении, `node node_modules/typescript/bin/tsc --noEmit`, сборка через `scripts/run-framework.mjs build`.

Табличные части: номера и выделение строк, перемещение, точный ввод количества и цены, подбор нескольких товаров с поиском по коду/артикулу/штрихкоду и остатками выбранного склада. Справочники объединены в одно окно; новые карточки создаются из документов без потери строк. Группы товаров — текстовые метки. Тесты: tests/line-entry.test.mjs и tests/directories-api.mjs.

Рабочее пространство «Миша и команда»: портфель покупателей, сопровождение Петей, Олегом, Наташей и Димой, ближайшие контакты, поручения с исполнителями и результатами, очередь проверки и нагрузка команды. Документы открываются из карточки клиента; новый заказ получает выбранного контрагента. Данные сохраняются на сервере с проверкой ревизий; рабочая база не получает учебных клиентов. Карточки помощников пока не являются отдельными учётными записями, персональный доступ и уведомления не подключены. Проверены 32 unit-теста, API команды, TypeScript, сборка и основные сценарии в браузере. Исходный коммит приложения: 6e7e959aecd30506756eceecab7852b0f3593b40.
