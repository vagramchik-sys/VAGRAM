# VAGRAM — проекты

Общий репозиторий исходников и материалов VAGRAM. Для действующих рабочих папок настроен регламент получения и сохранения изменений через Codex: [как работаем с GitHub](docs/workflow/README.md).

| Материал | Папка | Запуск |
|---|---|---|
| Дашборд маркетплейсов Ozon / Wildberries | [projects/marketplace-dashboard](projects/marketplace-dashboard) | Windows, Node.js 20+: `node server.cjs`, порт 4317 |
| Центр проектов, учет Ozon и ИИ-директора | [projects/project-center](projects/project-center) | Node.js 22+: `node server.cjs`, порт 8787 |
| Панель тендерного отдела | [projects/tender-dashboard](projects/tender-dashboard) | Открыть `dist/index.html` в браузере |
| Визуализация продаж SnapDock | [visualizations](visualizations) | Открыть HTML в браузере |
| Команда B2B e-commerce | [docs/team](docs/team) | Markdown |
| Предварительный бизнес-план производства крепежа | [docs/manufacturing/business-plan.md](docs/manufacturing/business-plan.md) | Markdown |

Команды запуска выполняются из папки соответствующего проекта. Подробности и ограничения — в README каждого приложения. Бизнес-план сохранен из ранее подготовленного ответа; это предварительные оценки, а не новые подтвержденные расчеты.

## Данные и доступы

В репозиторий включены исходники, документация, тесты и демонстрационные материалы. Рабочие базы, учетные записи сотрудников, история диалогов, ключи API, локальные подключения и настройки хостинга не включены. После клонирования приложения требуют первоначальной настройки; подключенные локально магазины и их показатели не переносятся.

Центр проектов при первом запуске предложит создать администратора. Для ИИ-директоров требуется отдельно настроенный локальный Codex CLI. Сам репозиторий не запускает приложения и не публикует сайт.

## Проверки

- Все проекты и синхронизация: `node scripts/check.cjs` из корня репозитория.
- Дашборд маркетплейсов: `node --test test/*.test.cjs`.
- Центр проектов: `node --test test/*-tests.cjs`.

Тесты центра перенесены вместе с проектом; пути к исходникам адаптированы к этой структуре.

## Работа с изменениями

Перед задачей Codex проверяет обновления, после завершения тестирует и сохраняет результат в GitHub. Каждая правка имеет отдельный коммит; конфликтующие версии не перезаписываются автоматически. Публикация выполняется через подключенный GitHub plugin, пока для терминального Git не настроен отдельный вход. Это не фоновая синхронизация и не автоматическое обновление работающих серверов.
